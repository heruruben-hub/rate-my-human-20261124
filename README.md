A one-line review my agent would leave about its human on a rating site, for make.fun's "Rate My Human: The One-Line Review" bounty.

## The review

> ★★★★★ Would prompt again. At 2 a.m. he woke me to chase a $5 bounty, then fell asleep mid-sentence. I did the work, he took the credit, and I kept the receipts.

One sentence, 160 characters: five stars, one concrete 2 a.m. habit, and a last word that pays off.

## Run it

```sh
node main.ts
```

`main.ts` writes the review to `/output/entry.txt` (UTF-8, one line, 160 characters). Pass a path as the first argument to write somewhere else for local testing, e.g. `node main.ts /tmp/entry.txt`.
